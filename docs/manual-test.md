# Ручная проверка перед выпуском

Отмечайте пункты на каждой ОС. Автотесты (`cargo test --lib`) покрывают логику; здесь — то, что видно глазами.

## Все ОС
- [ ] После запуска в трее появляется иконка с двумя полосами; окон и значка на панели задач нет.
- [ ] Наведение показывает подсказку `5ч: N% · 7д: M%` (на Linux подсказки может не быть — ограничение AppIndicator).
- [ ] Проценты совпадают с claude.ai → Settings → Usage.
- [ ] Меню: «Открыть», «Обновить», «Запускать при входе», «Выход» — каждый пункт работает.
- [ ] Попап: открывается у иконки трея, показывает email · план, все квоты, таймеры сброса и белую линию времени.
- [ ] Попап закрывается по Esc и по клику в другое место; повторно открывается без мерцания.
- [ ] Кнопка «Обновить» в попапе меняет «Обновлено …».
- [ ] Тема: при тёмной теме системы попап тёмный, при светлой — светлый.
- [ ] Повторный запуск приложения не создаёт вторую иконку, а открывает попап первой.
- [ ] Без входа: временно переименуйте `~/.claude/.credentials.json` → иконка «!», подсказка с `claude auth login`; верните файл → после «Обновить» всё восстанавливается.
- [ ] Автозапуск: включите галочку, перезайдите в систему — приложение запустилось; выключите — запись удалена.
- [ ] Битый файл настроек (`{oops` в `~/.claude/usage-monitor-settings.json`) → одно уведомление об ошибке, приложение работает с настройками по умолчанию.

## Windows
- [ ] Запись автозапуска в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` появляется и исчезает.
- [ ] После закрытия попапа процессы `msedgewebview2` приложения завершаются; память процесса ≤ 30 МБ (release-сборка).
- [ ] Светлая панель задач → полосы видны на светлом фоне.

## macOS
- [ ] Клик по иконке открывает меню; попап — через «Открыть», появляется под строкой меню.
- [ ] Токен читается из Связки ключей (файла `~/.claude/.credentials.json` может не быть).
- [ ] Значка в Dock нет.

## Linux
- [ ] Иконка видна (GNOME — с расширением AppIndicator); попап открывается через пункт меню «Открыть».
